# Adding Translations

This guide explains how to add translations to a shared project. This is for **community members** who have already accessed the project.

## Before You Start

Make sure you have:
- Opened the project using the link or share code
- A good internet connection
- A keyboard (easier than on-screen keyboard)
- Understanding of what needs to be translated

## The Translation Table

Each sentence in the text is shown as a table with three rows:

### Row 1: Baseline (Original Text)
- Shows the original text in boxes
- One word per box
- You **cannot edit** these boxes
- This is what you're translating FROM

### Row 2: WFW (Word-for-Word Translation)
- One empty box under each original word
- Add a translation for each word above it
- These should be literal, rough translations
- Don't worry about grammar - just word meaning

### Row 3: Free (Free Translation)
- One large box for the whole sentence
- Write a natural, complete sentence
- This should make sense in the target language
- Can use different word order

## How to Add Word-for-Word Translations

1. Click in the first empty box under a word
2. Type the translation for that word
3. Press **Tab** to move to the next box
4. Type the next translation
5. Continue until you've translated all words in the sentence

### Example:
```
Baseline:    [kata]  [ya]   [kwanza]
WFW:         [word]  [of]   [first]
```

### Tips for WFW:
- Keep it simple - one or two words maximum
- Don't add articles (a, the) unless necessary
- Don't worry about verb tense - use base form
- If a word has no good translation, use the closest word
- If unsure, skip it and come back later

## How to Add Free Translations

1. Click in the large box at the bottom of the sentence
2. Type a natural, complete sentence
3. Make it sound natural - not word-for-word
4. Use proper grammar and punctuation

### Example:
```
Baseline:    kata ya kwanza
Free:        The first word
```

### Tips for Free Translation:
- Read the whole sentence first
- Think about the meaning, not just words
- Use natural word order
- Make complete sentences
- Check spelling and grammar
- If you're not sure, ask the linguist

## Saving Your Work

**Good news:** Your translations save automatically!

### How Auto-Save Works:
1. You type a translation
2. You click outside the box or press Tab
3. You'll see "Saving..." appear briefly
4. Then you'll see "Saved"
5. Your work is now saved to the database

### Important:
- Wait for "Saved" before closing your browser
- Don't close the browser while "Saving..." is showing
- If you lose internet, your last saved work is safe
- Work saves every time you finish a box

## Working Through the Project

### Recommended Approach:
1. Start with the first sentence
2. Read the baseline carefully
3. Add word-for-word translations
4. Then add the free translation
5. Move to the next sentence
6. Take breaks when needed

### You Can:
- Work in any order (don't have to start at the beginning)
- Skip difficult sentences and come back later
- Work a little at a time over several days
- Leave notes in the free translation if you have questions

### Progress Tracking:
- The progress bar updates as you work
- A sentence is "complete" when it has a free translation
- You can see how much is left to do
- Others working on the project also update the progress

## Keyboard Shortcuts

- **Tab** - Move to next box
- **Shift+Tab** - Move to previous box
- **Enter** - New line (in free translation box only)
- **Ctrl+Z** - Undo (if you make a mistake)

## Special Characters

If you need special characters (accents, etc.):

### On Computer:
- Use your keyboard's language settings
- Copy and paste from character map
- Use keyboard shortcuts for your language

### On Phone/Tablet:
- Press and hold letters to see accents
- Switch to other keyboard languages in settings
- Use the special character keyboard

## Handling Difficult Words

If you encounter:

### Unknown Words:
- Skip it for now
- Ask the linguist for clarification
- Look it up if you have resources
- Leave a note in the free translation

### Cultural Terms:
- Translate the concept, not just the word
- Add explanation if needed
- Ask the linguist how they want it handled
- Use the closest equivalent

### Names and Places:
- Usually keep these the same
- Or use the standard translation if there is one
- Ask the linguist if unsure

## Quality Tips

### Good Translations:
- Accurate to the original meaning
- Natural in the target language
- Complete sentences for free translations
- Appropriate tone (formal/informal)

### Avoid:
- Extremely literal translations (in free translation)
- Adding information that isn't there
- Leaving out important information
- Translating word-by-word without meaning

## Working with Others

Multiple people can work on the same project:

### This Means:
- Someone else might translate while you're working
- The progress bar updates for everyone
- You might see sentences already translated
- Don't duplicate work - move to untranslated sentences

### Tips for Collaboration:
- Start from different ends (one at beginning, one at end)
- Communicate with others working on it
- Don't overwrite someone else's work unless improving it
- If you disagree with a translation, discuss with the linguist

## Taking Breaks

It's OK to stop and come back later:

1. Wait for "Saved" to appear
2. You can close the browser
3. To return: Use the same link or share code
4. Your work will still be there
5. Continue where you left off

## Troubleshooting

### "My translation disappeared"
- Check if you waited for "Saved" before closing
- Refresh the page - it might reappear
- Check if someone else changed it
- Contact the linguist

### "I can't type in a box"
- Click directly in the box
- Make sure the box isn't read-only (baseline boxes can't be edited)
- Try a different browser
- Refresh the page

### "Saving..." never changes to "Saved"
- Check your internet connection
- Wait a bit longer (slow connections take time)
- Refresh the page to see if it saved
- Try typing in a different box

### "I made a mistake"
- Click back in the box
- Edit your translation
- It will save again automatically
- Or use Ctrl+Z to undo immediately

### "The progress bar doesn't update"
- Refresh the page
- Progress updates when free translations are added
- WFW translations alone don't update progress

## Best Practices

1. **Read First** - Read the whole baseline sentence before translating
2. **Think** - Consider the meaning, not just words
3. **Be Natural** - Free translations should sound natural
4. **Be Consistent** - Translate similar words the same way
5. **Ask Questions** - Contact the linguist if unsure
6. **Take Breaks** - Don't rush, quality matters
7. **Save Often** - Make sure you see "Saved" regularly

## When You're Done

After completing your work:

1. Check the progress bar
2. Review a few of your translations
3. Make sure "Saved" appeared for your last translation
4. Let the linguist know you're finished
5. They'll download and review your work

## Getting Help

If you need help:
- Contact the linguist who shared the project
- Explain what you're having trouble with
- Send a screenshot if possible
- They're happy to help!
