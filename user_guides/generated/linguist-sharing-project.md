# Sharing Your Project with Community Members

This guide explains how to share your translation project with community members so they can add translations.

## What Community Members Need

Community members **do not need** to:
- Create an account
- Sign up or log in
- Install any software
- Download any files

They **only need**:
- The share link you provide
- A web browser
- Internet connection

## Method 1: Share the Complete Link (Recommended)

This is the easiest method for community members.

1. After uploading your project, find it in your dashboard
2. Look for the **share link** - it looks like: `https://your-app.com/#p/ABC123XYZ`
3. Copy the complete link
4. Send it to community members via:
   - Email
   - WhatsApp
   - Text message
   - Any messaging app they use

### Why This Method is Best
- Community members just click the link
- No typing required
- Fewer chances for errors
- Works on phones and computers

## Method 2: Share the Share Code

If you can't share a clickable link (for example, in a printed document):

1. Find the 9-character **share code** for your project
2. The code looks like: `ABC123XYZ`
3. Tell community members to:
   - Go to the web application URL
   - Enter the share code when prompted
   - Click to access the project

### When to Use This Method
- Printing instructions
- Writing the code on paper
- Situations where links don't work

## How to Send the Link

### Via Email
```
Subject: Translation Project - [Text Title]

Hello,

I would like your help translating a text. Please click this link to access the project:

[paste the share link here]

Instructions:
1. Click the link
2. You'll see the text broken into sentences
3. Add word-for-word translations in the WFW row
4. Add free translations in the Free row
5. Your work saves automatically

Thank you for your help!
```

### Via WhatsApp or Text Message
```
Hi! Can you help translate this text? Click here:
[paste the share link here]

Just add the translations and they'll save automatically. Thanks!
```

## Important Information for Community Members

Make sure to tell them:

1. **No login required** - They can start translating immediately
2. **Auto-save** - Changes save automatically, watch for "Saved" message
3. **Progress tracking** - They can see how much is completed
4. **Mobile-friendly** - Works on phones and computers
5. **Multiple people can work** - Several people can translate at the same time

## Checking Progress

After sharing your project:

1. Log into your dashboard
2. Look at your project
3. See the progress percentage
4. This updates as community members add translations
5. You can download results at any time (even before 100% completion)

## Managing Access

### Share Code Security
- Share codes are 9 random characters
- Very difficult to guess
- Only share with people you want to have access
- There are over 100 billion possible combinations

### If You Need to Restrict Access
Currently, anyone with the link can access and translate. For future versions, features may include:
- Password protection
- Expiring links
- Access logs

For now, only share the link with trusted community members.

## Troubleshooting

### "The link doesn't work"
- Make sure you copied the complete link
- Check for extra spaces at the beginning or end
- Try copying again
- Verify your project was uploaded successfully

### "Community members can't access the project"
- Make sure they have internet connection
- Try the link yourself to verify it works
- Send them the direct link, not just the code
- Check if they're using an old/incompatible browser

### "I lost the share link"
- Log into your dashboard
- Find your project
- The share link is always displayed there
- You can copy it again anytime

## Tips for Successful Collaboration

1. **Explain the task clearly** - Tell them what you need translated
2. **Set expectations** - Let them know how long you think it will take
3. **Provide context** - Explain what the text is about
4. **Check in regularly** - Monitor progress and answer questions
5. **Express gratitude** - Thank them for their help!
6. **Test first** - Share a small test project before large texts

## Example Project Introduction

When sharing a project, you might say:

```
I'm working on translating traditional stories from our language.
This text is about [brief description]. I need help with:

1. Word-for-word translations (WFW row)
2. Free translations in English (Free row)

The project has [number] sentences. Feel free to translate as many
or as few as you have time for. Your work saves automatically.

Here's the link: [share link]

Please let me know if you have any questions!
```
