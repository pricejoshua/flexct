# Uploading Your Translation Project

This guide explains how to upload your interlinear text data to the web application so community members can add translations.

## Before You Start

Make sure you have:
- Exported your text from FLEx using the FlexTools export script
- The exported JSON file saved on your computer
- Logged into the web application

## Step 1: Access Your Dashboard

1. Log into the web application with your email and password
2. You'll see your linguist dashboard
3. This page shows all your current projects

## Step 2: Upload Your Project

1. Look for the **"Upload New Project"** button on your dashboard
2. Click the button
3. A file selection window will open
4. Navigate to where you saved your exported JSON file
5. Select the JSON file
6. Click **"Open"** or **"Select"**

**Important:** The file must be in JSON format (ending with .json). Files exported from FLEx using the FlexTools script are automatically in the correct format.

## Step 3: Wait for Upload to Complete

1. You'll see a progress indicator while the file uploads
2. This may take a few seconds to a minute depending on:
   - The size of your file
   - Your internet connection speed
3. **Do not close the browser window** while uploading

## Step 4: Confirm Upload Success

Once the upload is complete:

1. You'll see your new project appear in your project list
2. The project will show:
   - The title of your text
   - The date it was uploaded
   - A share code (9-character code)
   - A share link
   - Progress information (0% completed at first)

## Understanding Your Project Information

### Share Code
- A 9-character code (like "ABC123XYZ")
- Unique to your project
- Used to access the project

### Share Link
- A complete URL that opens directly to your project
- Looks like: `https://your-app.com/#p/ABC123XYZ`
- More convenient than typing the share code

### Progress
- Shows what percentage of segments have translations
- A segment is "completed" when it has a free translation
- Updates automatically as community members work

## Troubleshooting

### "File upload failed"
- Check your internet connection
- Make sure the file is in JSON format
- Try uploading again
- If the file is very large (over 5MB), it may time out

### "Invalid file format"
- The file must be exported from FLEx using the FlexTools script
- Make sure the file hasn't been modified
- Check that the file extension is .json

### "Upload takes too long"
- Large texts with many segments take longer
- Check your internet connection speed
- Be patient - don't refresh the page

### "I can't find my exported file"
- Check your Downloads folder
- Look in the folder you specified when exporting from FLEx
- Make sure you completed the export process in FlexTools

## What's Next?

After uploading successfully:
- Share the project link with community members (see "Sharing Your Project" guide)
- Community members can start adding translations
- You can download the results at any time (see "Downloading Results" guide)

## Tips

- **Keep the original JSON file** - You'll need it if you need to re-upload
- **Upload one text at a time** - Easier to manage and share
- **Check the text title** - Make sure it's descriptive so community members know what they're translating
- **Test with a small text first** - Upload a short text to make sure everything works before uploading large texts
