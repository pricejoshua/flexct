# Accessing a Shared Translation Project

This guide is for **community members** who have been invited to help translate a text. You do NOT need to create an account or download any software!

## What You've Received

Your linguist should have sent you either:
- A **link** (like `https://app.com/#p/ABC123XYZ`) - easier option!
- A **9-character code** (like `ABC123XYZ`) - if no link available

## Method 1: Using the Link (Easiest)

If you received a link:

1. Click on the link
2. That's it! The project will open automatically
3. You can start translating immediately

**Works on:**
- Computers (Windows, Mac, Linux)
- Smartphones (iPhone, Android)
- Tablets (iPad, Android tablets)

## Method 2: Using the Share Code

If you only have the code:

1. Open your web browser
2. Go to the web application URL (ask the linguist if you don't have it)
3. Look for where to enter the share code
4. Type in the 9-character code carefully
5. Click the button to open the project

**Important:** Type the code exactly as given - codes are case-sensitive (uppercase/lowercase matters).

## What You'll See

When the project opens, you'll see:

1. **The text title** at the top
2. **Language selector** (usually set to English)
3. **Progress bar** showing how much is completed
4. **Table with rows** for each sentence containing:
   - **Baseline row** - The original text in the vernacular language
   - **WFW row** - Where you add word-for-word translations
   - **Free row** - Where you add free translations

## No Account Needed

You can translate immediately without:
- Creating an account
- Providing an email
- Creating a password
- Giving personal information

Just start typing!

## Understanding the Interface

### Baseline Row
- Shows the original text
- You cannot edit this
- Each word is in a separate box
- This is the language you're helping translate FROM

### WFW Row (Word-for-Word)
- One box for each word in the baseline
- Add a translation for each word
- These are rough, literal translations
- Don't worry about making complete sentences here

### Free Row
- One box for the entire sentence
- Write a natural translation
- This should be a complete, readable sentence
- Can be different word order than the baseline

### Progress Bar
- Shows percentage of sentences completed
- A sentence is "complete" when it has a free translation
- Helps you see how much work is left

## Troubleshooting

### "The link doesn't open"
- Check your internet connection
- Make sure you copied the complete link
- Try a different browser
- Ask the linguist to send the link again

### "I entered the code but nothing happens"
- Check that you typed it exactly right
- Make sure there are no spaces
- Check uppercase and lowercase letters
- Ask the linguist to confirm the code

### "The page is blank or won't load"
- Refresh the page
- Check your internet connection
- Try a different browser
- Clear your browser cache

### "I can see the project but can't type"
- Click inside the box where you want to type
- Make sure JavaScript is enabled in your browser
- Try a different browser
- Refresh the page

## Browser Compatibility

Works best with:
- **Chrome** (recommended)
- **Firefox**
- **Safari** (Mac/iPhone)
- **Edge** (Windows)

Should work on all modern browsers updated within the last 2 years.

## Mobile Devices

Yes! You can translate on your phone or tablet:
- The interface adapts to small screens
- Use portrait or landscape mode
- Keyboard works the same as computer
- Saves automatically just like on computer

**Tips for mobile:**
- Landscape mode gives more space
- Zoom in if text is too small
- Make sure auto-correct doesn't change words
- Keep your screen on while working (it won't save if screen locks)

## What's Next?

Now that you can access the project:
- Read the "Adding Translations" guide to learn how to translate
- Start with a few sentences to get comfortable
- Work at your own pace
- Your translations save automatically

## Getting Help

If you have problems:
- Contact the linguist who shared the project
- Try the troubleshooting steps above
- Try a different device or browser
- Check the "Adding Translations" guide for more help

## Privacy and Security

- The share code allows anyone who has it to access the project
- Don't share the code/link unless asked by the linguist
- The system doesn't collect personal information about you
- Your translations are saved to help the linguist

## Important Notes

1. **Keep the link/code safe** - You'll need it each time you want to work
2. **Bookmark the page** - Makes it easy to return to the project
3. **Internet required** - You must be online to translate
4. **Multiple sessions OK** - You can open the project on different devices (but not at the same time)
